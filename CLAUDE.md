# CVMatch Web
- Frontend de CVMatch: Next.js (App Router) + TypeScript + Tailwind.
- Backend FastAPI en http://localhost:8000. Endpoints: POST /analyze, GET /analyses, GET /analyses/{id}.
- Pantallas: app/page.tsx (home), app/historial/page.tsx (lista), app/historial/[id]/page.tsx (detalle).
- Estilo: fondo #0A0A0F, tarjetas #13131A, acento púrpura. Textos de UI en español rioplatense.
- Quien usa esto está aprendiendo frontend: explicá cada cambio brevemente.
